# 📚 勉強記録トラッカー

勉強時間を記録・可視化できるシンプルなWebアプリです。  
Python（Streamlit）を用いて開発し、データの入力・分析・編集・保存まで一通り行えます。

---

## 概要

このアプリは、日々の勉強時間を記録し、以下の分析を行うことができます：

- 日別の学習時間の推移
- 科目ごとの学習割合
- 合計時間・平均時間などを分析して表示

CSVファイルを使ってデータの保存・復元が可能な、軽量なデータ管理アプリです。

---

## 主な機能

### 記録機能
- 日付・科目・勉強時間を入力
- 既存の科目選択 or 新規追加

### データ分析
- 総勉強時間・日数・平均時間の表示
- 最も勉強した科目の自動算出
- 日別の学習量（積み上げ棒グラフ）
- 科目別の学習割合（円グラフ）

### フィルタ機能
- 日付範囲を指定してデータを絞り込み

### 編集・削除
- 任意のデータを選択して編集
- 不要なデータの削除

### データ管理
- CSV形式でデータをダウンロード
- CSVアップロードでデータを復元

---

## データの取り扱い

- 本アプリは**サーバーにデータを保存しません**
- データはブラウザのセッション内でのみ保持されます
- ページを閉じるとデータは消去されます

### 利用方法
1. 終了前に必ずCSVをダウンロードする  
2. 再開時はCSVをアップロードして、元の状態を復元する
